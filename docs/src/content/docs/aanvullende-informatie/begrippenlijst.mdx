---
title: Begrippenlijst
description: Uitleg van belangrijke begrippen binnen FitStudy.
---


In dit onderdeel worden belangrijke begrippen uit FitStudy kort uitgelegd.

| Begrip | Betekenis |
|---|---|
| Dashboard | Startscherm van een gebruiker na het inloggen |
| Student | Gebruiker die FitStudy gebruikt voor studieplanning, voortgang en welzijn |
| Docent | Gebruiker die studenten begeleidt en informatie kan bekijken of toevoegen |
| Admin | Gebruiker die accounts, klassen, roosters en basisgegevens beheert |
| Planning | Onderdeel waarin taken en deadlines zichtbaar zijn |
| Studieprogramma | Overzicht van vakken, lessen en onderdelen |
| Focus Timer | Hulpmiddel om geconcentreerd te werken in tijdsblokken |
| Welzijn | Onderdeel waarin de student welzijnsgegevens kan registreren |
| Notificatie | Melding binnen FitStudy |
| Mijlpaal | Badge of prestatie die een student kan behalen |
