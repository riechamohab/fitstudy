In dit onderdeel worden belangrijke begrippen uit FitStudy kort uitgelegd.

De begrippenlijst helpt gebruikers om de termen in de handleiding en in de applicatie beter te begrijpen.

| Begrip | Betekenis |
|---|---|
| FitStudy | De webapplicatie die studenten ondersteunt bij studieplanning, voortgang, focus en welzijn. |
| Gebruiker | Een persoon die toegang heeft tot FitStudy. Dit kan een student, docent of administrator zijn. |
| Student | Gebruiker die FitStudy gebruikt om studieplanning, voortgang, focus en welzijn bij te houden. |
| Docent | Gebruiker die studenten begeleidt en informatie kan bekijken of toevoegen. |
| Administrator | Gebruiker die accounts, studenten, docenten, roosters en algemene mededelingen beheert. |
| Dashboard | Het startscherm dat een gebruiker ziet na het inloggen. |
| Student-dashboard | Dashboard voor studenten met toegang tot planning, studieprogramma, focus timer, notities, voortgang en welzijn. |
| Docent-dashboard | Dashboard voor docenten met toegang tot studenten, roosters, opdrachten, beoordelingen, welzijn en feedback. |
| Admin-dashboard | Dashboard voor administrators met toegang tot statistieken, studentenbeheer, docentenbeheer, roosterbeheer en mededelingenbeheer. |
| Portaal | Het hoofdscherm binnen een dashboard waar de belangrijkste informatie wordt weergegeven. |
| Planning | Onderdeel waarin studenten hun taken, deadlines en studieactiviteiten kunnen bekijken of beheren. |
| Rooster | Overzicht van lessen, vakken en tijdsblokken per klas. |
| Roosterbeheer | Onderdeel waarin de administrator weekroosters kan aanmaken, aanpassen of verwijderen. |
| Studieprogramma | Overzicht van vakken, lessen, hoofdstukken en onderdelen die gevolgd moeten worden. |
| Focus Timer | Hulpmiddel waarmee studenten geconcentreerd kunnen werken in vaste tijdsblokken. |
| Welzijn | Onderdeel waarin informatie over stress, welzijn en balans tijdens het studeren wordt bijgehouden. |
| Voortgang | Overzicht van behaalde resultaten, afgeronde taken en studieontwikkeling. |
| Notities | Onderdeel waarin studenten persoonlijke studienotities kunnen bekijken of beheren. |
| Mijlpaal | Een prestatie of badge die een student kan behalen binnen FitStudy. |
| Mededeling | Algemeen bericht dat door een administrator naar studenten, docenten of beide groepen kan worden gestuurd. |
| Feedback | Bericht of notitie van een docent om een student te begeleiden of te ondersteunen. |
| Beoordeling | Onderdeel waarin cijfers of resultaten van studenten kunnen worden ingevoerd of bekeken. |
| Account | Persoonlijke toegang van een gebruiker tot FitStudy. |
| Inloggen | Het aanmelden bij FitStudy met e-mailadres en wachtwoord. |
| Uitloggen | Het afsluiten van de actieve sessie via de knop Log out. |
| Sessie | De periode waarin een gebruiker is ingelogd in FitStudy. |
| Backend | Het technische deel van de applicatie dat gegevens verwerkt en communiceert met de database. |
| Frontend | Het zichtbare deel van de applicatie waarmee de gebruiker werkt in de browser. |
| Database | De plaats waar gegevens van FitStudy worden opgeslagen. |
| Neon | De online PostgreSQL-database die wordt gebruikt voor FitStudy. |
| API | De verbinding tussen frontend en backend waarmee gegevens worden opgehaald of opgeslagen. |
| Render | Het platform waarop de FitStudy applicatie online gedeployed kan worden. |

## Samenvatting

Deze begrippenlijst geeft een korte uitleg van de belangrijkste termen binnen FitStudy.

Wanneer een begrip in de handleiding niet direct duidelijk is, kan de gebruiker dit onderdeel raadplegen voor extra uitleg.
